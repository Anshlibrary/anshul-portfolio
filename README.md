# 🚀 Deployment on GitHub Pages

## Step 1 — Push Project to GitHub

```bash
git init
git add .
git commit -m "Initial portfolio upload"
git branch -M main
git remote add origin https://github.com/Anshlibrary/anshul-portfolio.git // It should be your url
git push -u origin main
```

---

## Step 2 — Enable GitHub Pages

Go to:

```text
GitHub Repository → Settings → Pages
```

Configure:

- Source → Deploy from Branch
- Branch → `main`
- Folder → `/root`

Save changes and GitHub will generate your live website link.
